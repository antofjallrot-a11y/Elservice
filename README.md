# Elservice Lund – webbplats

En responsiv svensk företagswebbplats för ett lokalt elföretag i Lund.

## Filer

- `index.html` – hela webbplatsens struktur och innehåll
- `style.css` – design och responsiv layout
- `script.js` – mobilmeny, årtal och kontaktformulär

## Publicera med GitHub Pages

1. Lägg filerna i ditt repository.
2. Gå till **Settings → Pages**.
3. Välj **Deploy from a branch**.
4. Välj exempelvis `main` och mappen `/ (root)`.
5. Spara.

GitHub Pages publicerar därefter webbplatsen på din Pages-adress.

## Logotyp

Webbplatsen använder logotypen från ditt GitHub-repository:

`antofjallrot-a11y/Elservice`

Om filnamnet ändras behöver bildadressen i `index.html` uppdateras.

## Viktigt före publicering

Byt gärna ut:
- telefonnummer
- e-postadress
- eventuella företagsuppgifter
- riktiga öppettider
- länkar till sociala medier

Kontaktformuläret är byggt utan backend och öppnar användarens e-postprogram via `mailto:`.
